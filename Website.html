Our Mission

Fragment focuses on fast, stable execution with a simple, no-ads, no-key experience.

Fragment was built for developers and power users who demand performance, stability, and creative freedom in Roblox scripting. I saw a landscape cluttered with malware-ridden, ad-infested executors hiding behind paywalls and key systems - and decided to build something different. No link bypasses. No waiting. Just download, run, and inject. I believe powerful software should be accessible to everyone, without friction or compromise. Fragment is, and always will be, completely keyless and ad-free. Note: The Velocity API integration requires a key - that key system belongs to Velocity, not us. Fragment itself has no key system of any kind.

Have you used this editor before?

This editor sends requests to the Velocity bridge running on this computer. Need a quick walkthrough?

  1. Type or paste text in the editor.
  2. Select + to make another tab. Double-click a tab or select it and press F2 to rename it.
  3. Your tabs and their text are saved in this browser.
  4. Start the local Velocity bridge first. Inject requests an attachment; Execute sends the current editor contents.
  5. The bridge listens at http://127.0.0.1:4873. The browser cannot read its response, so check the bridge window for confirmation or errors.
